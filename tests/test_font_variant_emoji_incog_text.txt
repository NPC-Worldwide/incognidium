What is font-variant-emoji?
The property controls how emoji characters are rendered: font-variant-emoji
• - Default rendering normal
• - Force text-style rendering (monochrome) text
• - Force emoji-style rendering (colorful) emoji
• - Use Unicode variation selectors unicode

developers control over whether emoji should render as colorful graphics or
monochrome text glyphs.
